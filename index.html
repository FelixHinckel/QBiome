    QBiome¶

    QBiome est un projet QGis conçu pour les inventaires naturalistes de terrain. Il s'utilise sur ordinateur via QGis pour préparer et traiter les données, et sur mobile via QField pour la saisie sur le terrain.

    Ce que contient QBiome¶

    Un projet QBiome se présente sous la forme d'un dossier contenant :

    • QBiome.qgz — le projet en lui-même
    • Donnees.gpkg — le GeoPackage qui rassemble toutes les données saisies
    • Referentiels.gpkg — le GeoPackage qui compile les référentiels externes (Taxref, statuts, Habref...)
    • DCIM — le dossier où seront enregistrées les photos prises dans le projet

    Modules disponibles¶

    • Observations opportunistes
    • Protocoles faune
    • Relevés phytosociologiques
    • Cartographie d'habitats
    • Zones humides
    • Sondages pédologiques

    Il existe aussi trois projets spécifiques : QFaune, QFlore et QFonge. Chacun de ces projets ne reprend que les modules essentiels pour alléger la saisie sur le terrain.

    Configuration recommandée¶

    Logiciel Version recommandée
    QGis 3.44
    QField 4.1.5 +

    QBiome n'a pas été testé avec QGis 4.x pour l'instant. Il est donc conseillé d'utiliser la version 3.44 LTR.

    Utiliser cette documentation¶

    La documentation suit le workflow chronologique d'une mission de terrain :

    Accéder au projet  →  Préparer son terrain  →  Saisie sur le terrain  →  Traitement des données

    Si c'est votre première utilisation, commencez par Accéder au projet pour installer QBiome sur votre mobile, puis Préparer son terrain avant votre première sortie.

    Pour les utilisateurs déjà familiers avec QField, vous pouvez aller directement à la section qui vous intéresse :

    • Saisie opportuniste — faune, flore, fonge
    • Protocoles faune — IPA, repasse, chiro, reptiles…
    • Relevés phytosociologiques
    • Cartographie d'habitats
    • Zones humides et pédologie

    Nouveautés v1.1¶

    Refonte du module Protocole

    Le système de protocoles a été entièrement repensé. Un protocole unique et généraliste remplace les couches séparées par taxon. Il s'adapte automatiquement au type de protocole sélectionné (IPA, Repasse, Enregistrement chiroptères, Plaque reptiles…) en affichant les champs pertinents. Un protocole peut désormais accueillir plusieurs passages successifs, chacun avec sa propre météo et ses propres observations.

    Amélioration du module Habitat

    Chaque entité habitat peut maintenant être caractérisée par jusqu'à trois typologies simultanées, avec un recouvrement renseigné pour chacune. Cela permet de représenter fidèlement les mosaïques d'habitats sans multiplier les géométries. Le formulaire signale automatiquement si la somme des recouvrements dépasse 100 %.

    Calcul du recouvrement en zones humides

    Les observations de flore liées à une zone humide permettent désormais de calculer directement le pourcentage de recouvrement par espèces hygrophiles.

    Performances améliorées

    Plusieurs actions de post-traitement ont été ajoutées pour réduire les temps de calcul et alléger l'application sur le terrain.
