    Déployer QBiome¶

    Il existe trois façons de déployer QBiome sur un appareil mobile. Le choix dépend principalement de votre infrastructure et de vos besoins en synchronisation.

    Méthode Connexion requise Synchro multi-utilisateurs Récupération des données
    QFieldCloud Oui ✓ Automatique
    Import zip / dossier Non — Manuelle
    Dossier système Non — Manuelle

    Méthode 1 — QFieldCloud¶

    QFieldCloud est la solution recommandée pour les projets impliquant plusieurs observateurs ou nécessitant des allers-retours fréquents entre le terrain et le bureau. Les données sont synchronisées via le cloud, sans manipulation de fichiers.

    Prérequis

    • Un compte sur QFieldCloud
    • Le plugin QFieldSync installé dans QGis

    Créer le projet sur le cloud

    Depuis QGis, ouvrir la barre d'outils QFieldSync et cliquer sur l'icône Cloud . Sélectionner Nouveau projet, garder l'option Convertir le projet actuel, puis valider. Le projet est maintenant hébergé sur QFieldCloud — c'est cette version qu'il faut conserver et ouvrir pour les prochaines sessions.

    Le nom du projet affiché dans QGis doit être suivi de (QFieldCloud) pour confirmer que vous travaillez bien sur la version synchronisée.

    Ouvrir le projet sur QField

    Depuis l'écran d'accueil de QField, aller dans Projets QFieldCloud et appuyer sur le projet pour le télécharger. Une fois téléchargé, le projet s'ouvre en rappuyant dessus.

    Récupérer les données du terrain

    Depuis QField, ouvrir le menu et appuyer sur l'icône cloud (le chiffre affiché correspond au nombre de modifications en attente). Deux options :

    • Pousser les modifications — envoie rapidement les données vers le cloud sans récupérer d'éventuelles modifications extérieures.
    • Synchroniser — harmonise le projet dans les deux sens, à utiliser si d'autres utilisateurs ont travaillé en parallèle.

    Sur QGis, il est possible d'accéder à la liste des projets cloud depuis la barre d'outils QFieldSync. Pour en ouvrir un, il faut le sélectionner dans la liste et cliquer sur Open Project. Une fois le projet ouvert, l'icône Synchroniser de la barre d'outils QFieldSync permet de récupérer les données depuis le cloud.

    Méthode 2 — Import zip ou dossier¶

    La méthode la plus simple pour un usage individuel sans connexion. Le projet est transféré manuellement vers l'appareil, et les données sont récupérées de la même façon.

    Déployer le projet

    Copier le dossier QBiome (ou le zipper) et le transférer sur l'appareil mobile par le moyen de votre choix (câble, partage réseau, messagerie, drive…).

    Depuis QField, aller dans Ouvrir un fichier local > bouton + en bas à droite, puis :

    • Importer un projet depuis un dossier — si vous avez transféré le dossier directement
    • Importer un projet depuis le ZIP — si vous avez transféré une archive

    Le projet est copié dans la mémoire de l'application. Pour le retrouver : Ouvrir un fichier local > Projets importés > nom du projet.

    Récupérer les données du terrain

    Depuis l'écran d'accueil de QField, aller dans Ouvrir un fichier local > Projets importés. Appuyer sur les trois points à droite du projet et sélectionner Envoyer le dossier compressé à. Choisir le moyen d'envoi (messagerie, mail, drive…), puis récupérer et dézipper l'archive sur l'ordinateur.

    Méthode 3 — Dossier système¶

    Cette méthode consiste à déposer le dossier directement dans la mémoire interne de l'application, sans passer par l'interface d'import de QField. Elle est utile si vous avez déjà accès au système de fichiers de l'appareil (via un gestionnaire de fichiers ou une connexion USB).

    Déployer le projet

    Copier le dossier QBiome à l'emplacement suivant sur l'appareil Android :

    Espace de stockage interne > Android > data > ch.opengis.qfield > files > Imported Projects

    Le projet apparaît ensuite dans QField via Ouvrir un fichier local > Projets importés.

    Récupérer les données du terrain

    Copier le dossier depuis le même emplacement vers l'ordinateur, par câble USB ou gestionnaire de fichiers. Le dossier contient le projet QGis avec toutes les données modifiées, prêt à être ouvert dir
